## Decisions taken (to be checked on units)

- **ROOT on FUNC + SCALE**, not a knob of its own: NOTE has no knob free in every case (ZOOM has knob G while NSRC
  is NOISE, ORDR and NLEN E and F while it is LIST), and FUNC + knob already means "the other end" on a range.
- **TURG value sources with another SOURCE use RHYTHM's TURING knobs as set there** (hidden while SRC is not TURG),
  as SHAPE = MAP uses MAP's knobs. `test_interplay` exempts them (`turg_reads`), as it does MAP's. The live TURING page
  (T3) can show the same fields.
- **VEL's VSRC offers RANGE and TURG only**: DYNAMICS has no knobs left for LIST's ORDR and LEN or NOISE's ZOOM. LIST
  and NOISE stay hidden there (`pg_never`; the all-shown screenshot build shows them).
- **AMT is a plain number** (0–100), not a percent: its middle means different things per flavour.
- **The Syntakt's 46 sets NOTE's and VEL's low ends and ROOT by poke**: dtboot's FUNC-held nudge does not reach the
  Syntakt's FUNC in analog-emu-st, so no FUNC + knob turn can be driven there (the Syntakt's 14-fields pokes its
  ranges too). The Rytm's 46 turns them with FUNC + knob; the frame's code is shared. On a unit: check FUNC + SCALE.
