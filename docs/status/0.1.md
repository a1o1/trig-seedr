## Decisions taken

1. **The track is mixed into every number** (`seed_take.salt`). Two tracks with the same seed and recipe do not
   give the same take, so a KICK and a HAT on seed 1 are not correlated. The seed shown is still the take number.
2. **VARY's walk-back limit.** When a slot has not re-rolled in the 64 takes up to n, it uses its anchor, a value
   that does not depend on n. This keeps "VARY 100: every take is equal" exact, at the cost that at VARY 100 the
   SEED knob makes no difference. At VARY 99 about 0.5 % more slots change per take than VARY implies.
3. **The field rotation (FLD, FROT, FMOD) runs last in the chain**, after TIME, because it rotates values that
   DYNAMICS to TIME write. It is a PLACE knob on the page.
4. **VEL defaults to DEF** (the track's default velocity), not 0.3's 80–120, so that a new recipe has every layer
   at 0. This is one of the changes listed for 0.4's release notes.
5. **A generating source keeps lanes and unknown flags** (`seed_step_clear`), as 0.3 kept sample locks while the
   lock share was 0. For a step with no origin, the device keeps the stored locks at that position, except the lanes.
6. **Origins are copies from the snapshot**, not moves. Two steps may name the same origin (PHRS pages, for
   example), and an original step that no step names is overwritten.
7. **Files for stages the plan did not place.** The NOTE and LOCK stages (`seed_note`, `seed_lock`) are in
   `values.c`, and EVRY and HUM are in `dyn.c`, all owned by 0.2.
8. **Shape levels are 0..255** and ranks are 0..`SEED_RANK_MAX` (65535).
9. **QUAL candidates** are numbered in `seed_take.cand`. Each candidate has its own numbers, and VARY relates
   take n + 1 to take n for the same candidate. F11's design note must say whether that satisfies P3 as wanted.

## How to test

```sh
make -C lib test        # test_seed_rng (I2, I4, I10, keys, shares) and test_seed_render; test_gen, test_groove as before
make -C lib coldfire    # every module, no undefined symbols
```

Result at review: test_gen 175 checks, test_groove 25, test_seed_render 80, test_seed_rng 31, none failed.
ColdFire: 11,104 bytes of text for all of `lib/`, no data or `.bss`, no undefined symbols. This was built with
Homebrew's m68k-elf-gcc 16.2.0 on the Mac; the reference compiler, gcc 14.2 in the Linux shell, has not been run
on this change.
