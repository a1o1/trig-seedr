## Decisions taken here (to be checked on units)

- **AMT's default is 25** (DJVU: a quarter of the steps new; CRPT: values drift, the rhythm stays; SHFT: a
  wild register). BIAS 50, LOOP 8, STRT SEED, FLAV DJVU.
- **SCALE applies to the notes NOTE writes** (NOTE not DEF), as every layer at 0 leaves its fields (V4); SCALE
  on SOURCE = TRACK with NOTE at DEF changes nothing.
- **STRT = TRACK's values** come from the original's notes (offset from the track's note, −24..+24, over
  0..65535; the default note in the middle), so TURG on NOTE gives the original's notes back while locked.
- **SHFT's BIAS** sets only the first pass's density; after that the register inverts, as on the module.
- **QUAL with TURG values**: the values follow the winning candidate's run (the dressing of other value sources
  stays candidate 0's, F11).
- **PHRS with TURING** runs the machine per phrase page, as RAND makes each page's phrase.
- **YOLO** does not roll TURING yet, so every YOLO roll keeps its recipe and its test vectors.
- **The struct's `spare`** keeps its size a multiple of 4: with 7 new int16_t fields the host padded to 196
  and ColdFire to 194, which 00-host's layout check caught.
- **Choice CHR** is kept although it leaves notes as OFF does (Labyrinth lists Chromatic and Unquantized apart).

## Open points

- The pages' rows for TURING's knobs (FLAV, LOOP, AMT, BIAS, STRT) and NOTE's SCALE, ROOT are T2's; until then
  SRC TURG uses the defaults.
- The live page (T3) uses `seed_turing_step` with its own take and running count; 12 bits of the count are used,
  so a run longer than 4,096 steps should change its take's seed.
