# S3: seedr on the Syntakt (the mod)

State: ready for review
Branch: worktree-s3-mod-st (from worktree-s0-2-emu-st; S2 merged in at b04d945)

## Done

- **`mods/seedr-st/seedr.c`**: the Syntakt's side of the frame (`frame/frame.h`), as `mods/seedr-ar2/seedr.c` is the
  Rytm's, on S2's device layer (`device/syntakt_st.h`; the stand-in device planned for before S2 merged was not
  needed). `mod.json`: the hook-bus core (`tools/st_build.sh --core mini`), `ev_tick`, `ev_draw`, `ev_key`,
  `ev_enc`, `-Os` and `-fno-tree-loop-distribute-patterns` after the profile's `-O3`.
  - Keys (ev+12, flags at ev+16: press 1, repeat 9, release 0x10): FUNC 1, TRK 2, PTN 3, BANK 4, MENU 5, GLOBAL 6,
    FX 7, TEMPO 8, RECORD 9, YES 12, NO 13, UP 14, DOWN 15, LEFT 16, RIGHT 17, PAGE 18, TRIG 19, SYN 20, FLTR 21,
    AMP 22, LFO 23 [measured with a probe mod; UP..PAGE from core-st's README]. seedr closes on MENU, GLOBAL, FX,
    SYN, FLTR, AMP and LFO.
  - Knobs: ev_enc's ID 1..8 = A..H (LEVEL 9), the signed count at ev+16 [measured]; the Rytm's 4 counts a step and
    two waking turns (analog-emu takes the Syntakt's counts per detent as the Rytm's [inferred]).
  - Opening: the third TRIG page (the TRIG view's sub-page 1, firmware notes section 6) and TRIG held + PAGE.
  - The tick: 30 Hz [measured: 300 ticks in 2,000M instructions, 10 s of analog-emu's clock].
  - The screen: the bitmap is `{vtable, 128, 64, 2, pixels}`, pixels at +16 in the Rytm's layout (8 bytes a
    column, row 0 at the top in bit 0 of the column's last byte) [measured with one pixel], so the frame draws as
    on the Rytm. **Text**: the OS's 6-pixel font (the object at `0x443db220`: height 6, a width per character, a
    16-bit offset per character, glyphs a byte a column with rows from the top in bits 2..7) [measured], drawn by
    seedr itself from the OS's data, so widths are exact and SF_INVERT clears the text on the title bar. Stock's
    text routine (`0x400f8bd0`, Synfact's ARP uses it) was measured too: y is the text's bottom row, as here.
  - Tracks: T1..T12 and FX; YOLO's roles by the machine once known, else by place (kick T1, snare T2, hats T3 and
    T12, the rest percussion, FX the meter) [inferred].
- **Memory (SD2)**: the core's 456 bytes, `.run` 52,424 and `.bss` 10,300 in the 64 KiB area, **2,320 bytes spare**.
  The device layer's state (`ST_SEED_STATE_SIZE`, about 140 KB) and the frame's take and screen buffers (11,126
  bytes) come from the native heap at the first tick (`st_attach`); until then the events pass through and seedr
  does not open. With the profile's `-O3` the code alone was 104,784 bytes; `-Os` after it gives 52,424.
- **`frame/frame.c`**: an opt-in `SD_FRAME_HEAP` (the Syntakt's part defines it) puts `orig`, `take_out`, `shown`,
  `work`, `scr_now`, `scr_drawn` and `scr_frame` behind pointers given by `frame_heap_attach`; four statics renamed
  (`f_orig`, `f_take_out`, `f_shown`, `f_work`) so the macros do not touch the struct members of the same names.
  **The Rytm's build is unchanged**: `mods/seedr-ar2` built from this branch and from b04d945 gives the same
  `.run` (58,101) and `.bss` (107,336), and the `.elemod` files differ only in their symbol tables (the four names;
  b04d945's table had lost `preview.c`'s own `work` to the name it shared with the frame's).
- **`lib/props.h`**: the Syntakt profile takes `device/st_params.h`'s fields (no retrig, as S0.5 and S2 found).
- **`tools/st_s3.sh`**: 18 PASS, about 105 s:
  the heap memory attached; TRIG, TRIG shows Euclidean and TRIG opens seedr; RIGHT steps all ten pages and LEFT
  wraps; knob A sets SEED 5 on TAKE and SRC RAND on RHYTHM; RECORD off, YES says RECORD TO GENERATE and writes
  nothing; RECORD on, YES leaves a take pending with trigs on track 1; NO says BACK TO THE ORIGINAL and the record
  and the lock store are byte for byte as before; NO again closes; on the FX track (the FX key) seedr opens and YES
  says NOT ON THE FX TRACK. Screens of every page in `build/emu/st-s3/`.

## Open points

- **A track's machine type** is not found (S2's open point), so LOCK lists the shared pages (filter, base-width on
  T1..T8, amp, LFO) and lane 1 starts on FATK. When it is found: `st_seed_set_machine(track, type)` from the tick.
- **ROTATE ALL** skips every track: the Syntakt's whole-step shift is not found (firmware notes section 8).
- **The modified mark** (`sd_edited`) and **stock's overlays** (`sd_stock_overlay`: popups over the screen) are not
  found: seedr does not mark the project and draws over a popup.
- **VIEW** shows retrig (`R-`) though the Syntakt has none; `frame/view.c` does not yet follow the track's fields.
- **LOCK's RNGE** shows the Rytm's default range (1-8, the sample slot's); a lane's range default per parameter is
  for S4 or later.
- `frame/test_pages` has no Syntakt build (it uses its own capabilities, not `props.h`).
- The `lib/props.h` profile's lockable parameters are still placeholders: `st_params.h` builds a track's list at
  run time, which a static profile cannot take as it is.
- Whether the sequencer plays the take (S2's open point) and the take against `tools/seedref` are S4's.
- The knobs' counts per detent on a unit are not measured.
