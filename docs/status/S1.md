# S1: two devices in the code

State: ready for review (S1.1, S1.2); S1.3 not needed yet
Branch: worktree-s1-split (from worktree-s0-2-emu-st, plan commit c6a620b)

## Done

- **S1.1, the frame.** `mods/seedr-ar2/seedr.c` is split in two:
  - `frame/frame.c`: everything that does not depend on the instrument (keys and knobs, pages, the recipe store,
    generate and apply, YOLO, ROTATE ALL's loop, the screen). `frame/pages.c`, `pages.h`, `preview.c`, `preview.h`,
    `view.c` and the host tests `test_pages.c`, `test_interplay.c` moved there from `mods/seedr-ar2/`.
  - `frame/frame.h`: the device part's interface: macros (tracks, the FX track, the tick rate, key codes and event
    fields, the knobs' counts) and 16 static functions (`sd_device`, `sd_current`, `sd_track_length`,
    `sd_track_fields`, `sd_track_name`, `sd_track_role`, `sd_grid_recording`, `sd_euclid`, `sd_rotate`, `sd_edited`,
    `sd_trig_subpage`, `sd_request_frame`, `sd_stock_overlay`, `sd_pixels`, `sd_text_draw`, `sd_text_width`,
    `sd_font_height`).
  - `mods/seedr-ar2/seedr.c`: the Rytm's side only (the 29 device calls, the key codes, the TRIG sub-page,
    `RT_SHIFT`, the core's text), then `#include "../../frame/frame.c"`: one translation unit, so the Rytm's inline
    device functions stay inline. `preview.c` and `view.c` are compiled on their own and draw text through two frame
    exports, `sf_text` and `sf_text_width` (`frame/preview.h`, flags `SF_LEFT`, `SF_RIGHT`, `SF_INVERT`; the Rytm
    part checks at compile time that they equal the core's `CORE_*`).
  - `mods/seedr-ar2/Makefile` runs `frame/Makefile`'s tests, so `make -C mods/seedr-ar2 test` (00-host) is unchanged;
    `tools/emu.sh` rebuilds when `frame/` changes.
- **S1.2, a second profile.** `lib/props.h` has a Syntakt-shaped profile behind `-DPROP_DEVICE_ST` (13 tracks, 64
  steps, note, velocity, length, micro timing −23..+23, condition, retrig and locks, no accent or slide, six
  placeholder lockable parameters, two signed). **Provisional**: TODO S0.5, switch to `device/st_params.h`. `lib/Makefile`
  builds every test that includes `props.h` a second time as `test_<name>_st` and runs it; `frame/Makefile` builds
  `test_interplay_st`.

## Findings

- `test_interplay` assumed every device has the accent flag: on the Syntakt profile ACC and AMOD are hidden, as
  `pages.c` says they should be for a device without `SEED_F_ACCENT`. The check now follows the profile's fields; on
  the Rytm profile it runs as before.
- The pixel layout (`pv_dot`: 128 × 64, 8 bytes a column) and the 20 Hz tick are the Rytm's; the frame now takes the
  tick from `SD_TICK_HZ`, but the pixel layout is still assumed in `frame/preview.h` and `frame.c`. S0.4 checks the
  Syntakt's bitmap.
- The Syntakt core (Synfact `core-st`) has no `core_text_draw`; `sd_text_draw` and its two siblings are where the
  Syntakt part maps text onto what that core gives.
- `43-yolo` gives 26 checks here; `docs/testing.md` says 29. The script is unchanged by this task, so the count is
  not the split's; the documented number is to be checked at the next count update.
- S1.3 is not needed yet: S0.2's `tools/emu_st.sh` sources `tools/emu.sh` unchanged and replaces what differs.
