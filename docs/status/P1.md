# P1: the Syntakt's open points

State: ready for review
Branch: worktree-p1-polish-st (from 9d8fb98, with worktree-s0-2-emu-st merged at 4424eb2)

## Done

- **Stock's popups** (`mods/seedr-st/seedr.c`, `sd_stock_overlay`). seedr drew over every popup and whole-screen
  menu, even TEMPO's. It now walks the view controller's list as elekloader core-ar2's `core_stock_overlay` does on
  the Rytm, knowing each view by its RTTI class name, and steps aside:
  - when the main screen's stack is gone (it ends with HelpBubbleView, `0x402374f0`): TEMPO (TempoMenuView), FUNC +
    PTN (ClickMenuView), FUNC + TRK (TrackNoteMenuView);
  - when an overlay sits after HelpBubbleView: PatternSelectView (PTN, BANK), TrackSelectionView (TRK), TapTempoView
    (FUNC + TEMPO), any `*MenuView` or `*Window`.

  QuickMuteMenuView (up while FUNC is held) and PermanentMuteMenuView (FUNC + BANK) draw nothing over the page, so
  seedr keeps its screen for FUNC + YES and FUNC + knob. All measured in analog-emu with seedr open and with stock's
  page (screenshots under build/), with the new `tools/st_views.py`.
- **`tools/st_s3.sh`**, 30 passed (12 new): each popup moves seedr aside and seedr stays open; FUNC held keeps
  seedr's screen byte for byte, with QuickMuteMenuView up; PTN latches stock's pattern select, PTN again cancels it
  and seedr's screen comes back byte for byte.
- **A Syntakt fuzz sample**: `lib/test_fuzz.c --sample-st N SEED TYPE TRACK` makes recipes on the list
  `st_track_params` builds for that track and machine (SD4), so both lanes go anywhere in it with values in range.
  `tools/tests-st/41-fuzz-sample.sh` reads each track's machine as seedr did and samples tracks 1, 12, 4 and 9:
  17 passed (8 samples, machines 0, 32, 1 and 20; each take = `seedref --device st`, NO byte for byte, FUNC + YES).
- **`frame/test_pages` on the Syntakt** (`test_pages_st`, in `make -C frame test`): no row needing retrig, accent
  or slide shows; LOCK's PARM stays in the list on both lanes. 3,977 checks, 0 failed. Three Rytm-shaped checks now
  follow the device's fields and parameters; the Rytm's counts are unchanged (3,753 and 3,766).

## Findings

- On the Syntakt, PTN latches pattern select (the header shows "A??" until a trig key or PTN again); seedr stays
  aside while it is up, as it should.
- FUNC + RECORD shows "Copy Pattern A01" in stock's header while FUNC is held; with seedr open that hint is not
  shown (QuickMuteMenuView is the view, and it must not move seedr aside). The same holds on the Rytm.
