# 0.3: Page framework

State: ready for review
Branch: worktree-m0-pages

## Done

- **`mods/seedr-ar2/pages.c`, `pages.h`: the table-driven pages.** Every knob of design section 5 is a row of one
  table, `pg_rows`: page, knob, label, where its value lives (the track's recipe, the lane in view, the pattern's
  shared MAP settings, TOOLS, the VIEW cursor), how a turn changes it, how it reads, its limits, the `seed_have_…`
  flag that must be set, the `SEED_F_…` field the track must have, and a condition on another setting (RHYTHM's
  knobs by SRC, CVAL by CTYP, AMT by SHAPE, ORDR / NLEN / ZOOM by the value source, and so on). Choice values carry
  their own flag (SRC EUCLID needs `seed_have_euclid`, SHAPE RANK needs `seed_have_rank`, …). A page shows when
  one of its rows does. Each row names its owner task in a comment, so a workstream edits only its rows.
- **`mods/seedr-ar2/seedr.c`: keys, navigation, recipe store, audition, drawing.**
  - LEFT / RIGHT: previous / next page shown, wrapping. UP / DOWN: LOCK's lane. PAGE, the TRIG keys and
    transport go to stock. TRIG cycle and TRIG held + PAGE open as in 0.3.
  - One recipe per track (V5) for the pattern in play, made by `seed_recipe_init` (V6, A7) the first time the
    track is shown.
  - YES renders the recipe from the original through `seed_render` (V2); YES with no knob turned since the track's
    last YES takes the next seed; NO restores; FUNC + YES keeps; leaving the track or pattern keeps. A render
    error writes nothing, says why for 2 s (NOT AVAILABLE YET, NO LOCK ROWS LEFT, …), and starts no audition.
  - TOOLS: ROTATE ALL with its own YES (V7), 0.3's whole-step rotation through stock's trig shift.
  - Title bar: page (and lane), track, source (`TRK` or `S` + seed), `AUD` while auditioning, a page mark per page
    shown with the one in view longer. Body: two rows of four cells as 0.3; a value too wide for its cell
    shows its low end and `+`, and the whole range appears in the strip while it is turned.
  - Bottom strip (the preview placeholder): the track as it is now, 2 px a step, bar height = velocity, a dot on
    every 4th empty step; messages replace it for 2 s. F10 replaces the source with the render.
  - VIEW: knob A moves the step cursor; the cursor's step also has a mark over the strip.
  - A provisional device block (`struct seed_dev` built on 0.3's `rt_*` calls), marked for 0.4 to replace.
- **`mods/seedr-ar2/test_pages.c` + `Makefile`**: host tests of the tables, built twice (flags as they are;
  `SEEDR_SHOW_ALL`).
- **`tools/tests/03-pages.sh`**: the emulator test, standalone until 0.5's `tools/run_tests.sh` exists. It writes only
  under `build/pages/` and does not rebuild core.
- **Screenshots**: `docs/screens/0.3/`. `all-*.png` are the ten pages from the `SEEDR_SHOW_ALL` build (every row
  shown as its table stands; the values are the defaults on an empty track); `seedr-*.png` are the build as it is.
- `mod.json`: the new sources (`pages.c`, `seed_render.c`, `seed_rng.c`, every stage module), and a description
  of the new navigation. The version stays 0.3: 0.6 sets 0.4, and `tools/test_seedr.sh` uses the file name.

## Decisions taken

1. **Recipes belong to the pattern in play.** Changing pattern starts new recipes (the meter carried, A7), so a
   recipe made on one pattern's track never renders over another pattern's track. The other way, keeping 13
   recipes across patterns, would need V6's protective default re-decided per pattern. Cheap to change.
2. **Every knob and UP / DOWN are seedr's while it is open.** In 0.3, VIEW passed knobs to stock, and other pages
   passed the arrows. Stock's TRIG page knobs change trig defaults, which nobody would see under seedr's screen.
3. **SEED is 0..9999, without 0.3's FREE.** FUNC + SEED: 100 a step. FUNC + any other plain knob wider than 20
   values: 10 a step. FUNC + a range knob: its low end (as 0.3).
4. **A range with DEF** (VEL, LEN, NOTE) leaves DEF at a start value (VEL 100, LEN 1/16, NOTE +0) and returns
   to DEF when either end is turned below its minimum. Turning one end past the other moves both.
5. **Values must fit 30 px** (about six letters; M and W are wider). SRC RANDOM reads `RAND`. STRONG, NOTBAR,
   LEGATO and EUCLID fit.
6. **A new recipe on an empty track takes SOURCE = TRACK while no generator is built** (V6 says RANDOM), so
   until 0.2 lands a YES on an empty track writes nothing rather than refusing.
7. **SRC, NSRC, LOCK SRC and AMOD hide while only one of their values is built.** With today's flags (all 0) the
   pages shown are TAKE (SEED, VARY), VIEW and TOOLS.
8. **ROTATE ALL's audition survives a track change** (it covers every track); a take's ends as before.
9. **The FX track stays refused** ("NOT ON THE FX TRACK", as 0.3); the provisional caps give it no NOTE and no
   LOCKS, so those knobs hide there.

## How to test

```sh
make -C lib test && make -C lib coldfire            # unchanged by this task
make -C mods/seedr-ar2 test                         # the page tables, twice
WORKSPACE=~/dev/github/elektron B=~/dev/github/elektron/analog-emu/target/release ELEKLOADER_CROSS=m68k-elf- \
    sh tools/tests/03-pages.sh                      # emulator; needs core-0.13.elemod built
```

Results (Mac, m68k-elf-gcc 16.2.0, analog-emu's Mac build, 2026-11-15):

- host: `test_pages` 3,701 checks, `test_pages` (all shown) 3,742, none failed; `lib` tests as at 0.1
  (175, 25, 80, 31, none failed); `make -C lib coldfire`: no undefined symbols.
- emulator, `tools/tests/03-pages.sh`, 28 checks, all PASS:
  - **V10 verified.** On a 32-step BD with seedr open, RECORD + T1, T5, PAGE, T1, T9 put trigs on 1, 5, 17, 25,
    exactly as with seedr closed. The TRIG keys' LEDs match stock's (page 2 of 2), and seedr's screen stays up.
    Stock did not misbehave, so the fallback in plan section 10 is not needed.
  - LEFT / RIGHT visit the built pages (TAKE, VIEW, TOOLS) and wrap; in the `SEEDR_SHOW_ALL` build, all ten.
  - YES with SOURCE = TRACK and every layer at 0 leaves BD's record (0x395 bytes) and lock store (0x162a bytes)
    byte-identical (I1 through the device); NO, YES again (the next seed), FUNC + YES, NO to close.
  - The TRIG cycle (D17) and SRC closing, as 0.3.
  - ROTATE ALL +1 moves BD's steps, NO puts them back byte-identical, FUNC + YES keeps.
  - A YES on a layer that is not built (RHYTHM RANDOM, stub) writes nothing, says NOT AVAILABLE YET and starts
    no audition.
- Size: `.run` 35,552 bytes, `.bss` 97,156 (0.3: 35,156 and 88,572). core-ar2 0.13's mods' area is 5 MB.

Not run: `tools/test_seedr.sh` (0.3's parts 1–8). Its parts navigate with PAGE to GEN 1..3, METER, GROOVE and
ROTATE, which this task replaces, and they compare with `genref` (gen.c). They will fail on this branch; task 0.5
re-expresses them on the new structure (plan section 9).

## Open points

- **Gate 7.2** (`tools/run_tests.sh` in full) waits for 0.5. `tools/tests/03-pages.sh` follows the
  `NN-<name>.sh` name and prints PASS / FAIL lines; it may need 0.5's helpers once they exist.
- The page marks in the title bar are cleared pixels on its foot row: legible in the screenshots, to be judged on
  the unit's OLED.
- FLD offers LANE1 and LANE2 even on a one-lane device; a choice gated by a capability needs a field in
  `struct pg_choice` (cheap, not done).
- Built and checked on the Mac only (gcc 16.2); the reference Linux build (gcc 14.2) has not been run.

   `seedr.c` checks that `gen_groove` and `seed_groove` have the same size, and passes the tables to the context
   as `seed_groove`.
4. **Decisions 1, 3 and 6** are visible to users; confirm or change them before 0.4's release notes.
