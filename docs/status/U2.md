## Done

- **Why power off saved nothing** (S0.2's open point), traced in Syntakt OS 1.42's code [measured in analog-emu-st]:
  - The power-sense interrupt (vector 66's handler, `0x40001d88`) reads PPDSDR_C bit 2, as on the Rytm. On power
    loss it forces INTC1 source 30 (bit 30 of `0xFC050014`); that source's handler (`0x40001d5e`) calls the
    callback registered at `0x405d3770` (by `0x400bd878`): `0x400bcf7a`.
  - `0x400bcf7a` writes the COKI working state only if the byte `0x43be3154` is set (`0x400bd27c`); otherwise it
    parks the card (CMD0 `0xF0F0F0F0`, `0x400bd3fa`), which is the 0-sector run analog-emu showed.
  - `0x43be3154` is set by `0x400bd8a0`, called once from the timer callback `0x40082316` when `0x40002036` reads
    **PPDSDR_G bit 3** high: the Syntakt's supercap-charged signal (the Rytm's is PPDSDR_A bit 5). analog-emu had no
    model of that bit, so it read 0 and the save was never armed.
  - The `0x455406d0` this task started from is the eMMC driver's mutex (its owner word): when the card is busy at
    power off the callback resets the eSDHC first. It is not a gate.
- **The model** (analog-emu-st `src/io.rs`): on the Syntakt's main CPU only (its DSP link set), PPDSDR_G bit 3 reads
  charged unless `supercap_flat`; the other bits read as written. Rebuilt with `cargo build --release`.
- **Result:** the save is armed at boot (`0x43be3154` = 1); power off writes 8,000 sectors and slot `0x7a000`
  is valid; a cold boot on that card has the edit.
- **`tools/tests-st/03-save.sh`**: section 3 now checks the power-off save (8,000 sectors) and that the cold boot
  itself has the kept take (I9). Its LOAD PROJECT 002 check went: from a cold boot on project 002 its menu presses
  start at another row and loaded an empty project. Section 4 is the Rytm's A7 check on the Syntakt: a pending take
  at power off is on the card as it stood, nothing is pending after the boot, NO only closes. Because recipes are in
  RAM only (design A3), the new recipe after the boot is SRC = TRACK, whose take is the track itself, so section 4
  turns SRC to RAND to make a take that differs.
