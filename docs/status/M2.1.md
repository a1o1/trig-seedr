## What was found

### Knobs that had no effect

Measured first with a matrix (each knob turned from its default, per source, over 40 seeds, 16 and 64 steps), then
made exact by reading the engine. A knob that cannot change the take with the other settings as they are:

| Knob | Has no effect when | Treatment |
|---|---|---|
| TAKE PHRS | the track is 16 steps or shorter (`seed_render`: one phrase) | hidden (decision 1) |
| TAKE CVAR | the trig positions draw no random numbers: SRC = TRACK, EUCLID, COPY, or MAP with CHAOS below 4, each with SYNC 0 (takes n and n + 1 have the same trigs; CVAR acts only where they differ) | hidden |
| TAKE QUAL | the same (every candidate has the same trigs; only RHYTHM and PLACE differ between candidates) | hidden |
| RHYTHM ROLE | BIAS is 0 (the rank table is read only through BIAS: `src_random.c`, `score.c`) | hidden |
| DYNAMICS AMOD | ACC is 0 | hidden |
| TAKE SEED, VARY | no layer draws random numbers | kept (decision 7) |
| TAKE METR, BEAT | nothing reads the meter (BIAS 0, no meter shape, SYNC 0, no TOP, QUAL's fit off) | kept |
| PLACE FLD | the field is at its default on every trig (a generating source with that layer off) | kept |
| QUAL, CVAR at the ends | RAND with BIAS ±100, DENS 0 or 100; CVAR at VARY 100 | kept |

### Misbehaviour

1. **PHRS cut EUCLID's cycle into pages.** Each page rendered EUCLID as a 16-step phrase from the cycle's start, so
   on 64 steps STEPS 13 / PULS 5 became four copies of its first 16 steps; any STEPS that does not divide 16 changed
   rhythm when PHRS was turned on, and the letters could never matter (EUCLID draws no random numbers). Fixed in
   `seed_render.c` (decision 2).
2. **PHRS lost trigs on a short last page.** On a 24- or 40-step track the last page was rendered as 16 steps, of
   which the track keeps 8; ROT and SYNC turned real trigs (with their locks, on SOURCE = TRACK) into the 8 steps past
   the end, where they were dropped. Found by the host test's count check (TRACK: 2 trigs of 4, EUCLID: 23 of 24
   pulses, ...). Fixed in `seed_render.c` (decision 3).
3. **A:B's CVAL showed /10.** CVAL's default range is 10..21 (as X%'s codes); switched to CTYP = A:B the cell showed
   `/10` while `trig.c` uses B = 8. Fixed in `pages.c`'s text (decision 6).

No reachable recipe is refused: over 60,000 random recipes of values the pages can reach (every source and layer),
`seed_render` never returned an error, and every guarantee below held.

## Decisions taken

1. **Rows that cannot change the take are hidden** (PHRS, CVAR, QUAL, ROLE, AMOD). A row condition reads one value
   (`when_off`), and these rules read several or the track's length, so a row flag `PR_SENSE` names rows with a rule
   in `pages.c`'s `sense()`. Each rule holds exactly when the engine ignores the value, so a hidden value is harmless;
   `test_interplay` renders every hidden row's value both ways. The value is kept while hidden and applies again when
   the row shows (CVAR set on RAND, then SRC = TRACK: CVAR hides; SYNC raised: CVAR shows with its value).
2. **EUCLID under PHRS runs along the track**, like COPY and MASK: its pulses are placed over the whole length first,
   and each page starts from its share as generated steps (origin none); the letters dress them. `docs/v1/vary.md`
   lists it with the things that keep the track's positions.
3. **A short last page of TRACK, COPY or EUCLID is a phrase of its own length**, so ROT and SYNC wrap inside the
   track. RAND and MAP still make 16 steps and the track plays their start (F9's decision 3, golden vector
   `phrs-abcd-40` unchanged).
4. **MAP under PHRS stays a phrase**: each page plays the map's first 16 steps (with its letter's CHAOS lift), as
   the meter's ranks restart on each page; the map's steps 17–32 are not heard with PHRS on. Written in `vary.md`.
5. **SHAPE = MAP with another source** keeps reading PART, X and Y, which RHYTHM shows only with SRC = MAP
   (`docs/v1/map.md`: "It works with any source"). Not changed; the host test exempts these three rows there.
6. **CVAL with CTYP = A:B reads B 2..8** on the screen, as `trig.c` clamps it.
7. **Kept visible** although they can have no effect: SEED, VARY, METR, BEAT, FLD (each depends on several pages'
   settings), and QUAL / CVAR at the ends of BIAS, DENS and VARY (hiding them there would make them flicker while
   a knob is turned). EUCLID's PULS above STEPS (every step), STEPS above the track's length (the cycle's start),
   SKIP at or past the length (no trigs), MASK or COPY against the track itself, and COPY TRK = MTRK with MASK (AVOID
   leaves nothing, ONLY changes nothing) all do what the docs say, and the preview shows the result before YES.
8. **No refusal added**: nothing reachable misbehaves badly enough to need one once 1–3 are fixed.

`test_interplay`, per recipe (an original of 13, 16, 24, 40 or 64 steps with random steps, the other 12 tracks
random, every row of TAKE..TIME at a random reachable value about half the time, SRC at random):

1. **Hidden rows**: every row the pages hide, in both lane views, turned to another reachable value, leaves the take
   byte-identical (except decision 5's three rows with SHAPE = MAP, and rows sharing a value with a shown row).
2. **Every recipe**: rendered without refusal; twice the same (I2); length, fields and the steps past the length
   unchanged (I6); origins inside the track; SKIP's steps and MASK's steps hold no trig on the result (P5); written
   values in range (velocity, note, length, micro timing, condition, rate); with no MASK, SKIP or CVAR, the count the
   source promises (I5) through ROT and SYNC: TRACK keeps every trig, EUCLID its pulses (PHRS too), RAND its DENS
   count (PHRS off).
3. **I3 with every source and the TAKE knobs**: a shown knob of DYNAMICS, NOTE, LOCK, TRIG or TIME, turned, changes
   only its layer's fields (`props.h`'s `prop_owned`).
4. **PHRS and EUCLID**: 400 EUCLID recipes on 24, 40 and 64 steps with each PHRS: the trigs are PHRS OFF's, every
   origin none; with ABAB and a velocity range, pages 1 and 3 are dressed alike and 1 and 2 not.
5. **The `PR_SENSE` rules** one by one, and A:B's CVAL text.

## Open points

- **TRIG and TIME rows with their layer at 0**: CTYP and CVAL show at COND 0, RATE and RCUR at RTRG 0, TIME (TIME's
  share) without a groove. Outside M2.1's pages; the same `PR_SENSE` rule would hide them (`sense()` cases).
- **The other direction is not a test**: `test_interplay` proves a hidden row has no effect, not that a shown row
  always has one (decision 7 lists the known cases).
- **MAP, the meter and SYNC under PHRS** are phrase-relative (decision 4); SYNC on a page's first step moves it to
  the page's last step (round the phrase), as F5 and F9 built it.

   from the seed (RAND, MAP with CHAOS 4 or more, SYNC above 0); ROLE at BIAS 0; AMOD at ACC 0. A hidden value is

3. **A short last page** (decision 3): TRACK, COPY and EUCLID keep their trigs; RAND and MAP make a 16-step phrase

4. **MAP under PHRS** (decision 4): each page plays the map's first 16 steps. The alternative is MAP along the track
   (like EUCLID now), with the letters choosing only the CHAOS lift and the dressing; it would also need SHAPE = MAP
   and TOP to read the track's position, a change in `seed_render.c` and the contract.
5. **SHAPE = MAP with another source** (decision 5) reads PART, X and Y, which only RHYTHM with SRC = MAP shows. To
   set them, switch SRC to MAP and back. Showing them elsewhere needs a page with three free knobs (DYNAMICS has one).
