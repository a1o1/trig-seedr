# S0.5: the Syntakt's lockable parameters

State: ready for review
Branch: worktree-s0-5-params (from worktree-s0-2-emu-st)

## Done

- **`device/st_params.h`**: the Syntakt OS 1.42's capabilities as data, in the shape of `rytm_params.h`:
  - 44 machines (type, name, the tracks whose menu offers them, a YOLO role, lane 1's default, the SYN page's
    controls in knob order A..H, each with stock's id and its range);
  - the pages every track shows: filter (FATK FDEC FSUS FREL FRQ RES FENV FDLY, and BASE WDTH on digital
    tracks), amp (AATK AHLD ADEC DEL REV PAN VOL), LFO1 and LFO2 (SPD FADE SPH DEP each); the FX track's own
    Drive and amp page (DRV AATK AHLD ADEC ADEP DEL REV PAN VOL) and filter (with FPAN);
  - the fields: NOTE VEL LEN UTIME COND LOCKS on tracks 1..12; LEN UTIME COND LOCKS on the FX track; micro
    timing -23..+23;
  - `st_track_params(machine, track, ...)`: a track's list for lib/ (SD4), at most 34 entries, lane 1 on the
    machine's knob A (SMP1 on SP TWINSHOT), lane 2 on the filter's FRQ.
- **`tools/st_params.py`**: makes the header from the stock file (checks its sha256); nothing from the file but
  names, numbers and ranges goes into it.
- **`device/test_st_params.c`** (`make -C device test`): 101,684 checks, 0 failed: names, ranges, stock ids unique
  and < 505 per machine and page, every track's menu has its machines, every track and machine's list is one
  lib/ can take. The header also compiles for ColdFire (m68k-elf-gcc 16.2, freestanding, no undefined symbols;
  6.6 KB with every machine).
- **`tools/st_s05.sh`**: regenerates the header and checks it equals the committed one (PASS), and takes the
  screens the track facts come from (machine menus on tracks 1, 9, 12; SYN, FLTR, AMP, LFO on tracks 1, 9 and the
  FX track) into `build/emu/st-s05/`.
- `make -C lib test`: 24 tests, 0 failed.

## How each fact was found

| Fact | How |
|---|---|
| Stock parameter ids, names, ranges, defaults | [measured, static] the main OS's parameter table: 505 entries of 52 bytes at `0x4022d83c` (owner, Sound word, min / max / default in 8.8, a knob code at +0x1c, long and short name). The id is the entry's index: NOT2..NOT4 come out at `0x1e..0x20` and LFO1 at `0x56..`, as Synfact's POLY and LFO3 use them; Synfact's notes say stock scans ids 0..504 |
| Machine types and names | [measured, static] the list at `0x4022b228`, indexed by type: type 0 is BD MODERN, track 1's machine in the default project; 44 SP TWINSHOT, 20 SY DUAL VCO, 43 HH LAB match their controls |
| Knob order on a SYN page | [measured] the entry's knob code 0x81..0x88 = A..H; checked on screen for BD MODERN (track 1) and SY DUAL VCO (track 9) |
| Which machines each track offers | [measured] FUNC + SYN on tracks 1 and 5 (DIGITAL, 13 machines), 9, 10 and 11 (ANALOG DRUM, 20), 12 (ANALOG CYMBAL, 14). UT NOISE, UT IMPULSE and MIDI are on every analog track, MIDI on all twelve; DISABLE (no controls) on the analog tracks |
| The shared pages' controls | [measured] the FLTR, AMP and LFO pages on tracks 1, 9 and the FX track; BASE / WDTH only on the digital track |
| No retrig, accent or slide | [measured, static] the table has no such parameter; the TRIG pages show none |
| The MIDI machine's controls (CC1..8 VAL) | [inferred] the table's owner 0x39; its SYN page was not opened |
| Roles for YOLO | [inferred] from each machine's name (BD kick; SD, RS, CP back; CH, OH, HH hat; CY, CB, PC, UT perc; SY, SP, MIDI meter) |
| Lane defaults | [inferred] a choice, as the Rytm's: knob A (SMP1 on SP TWINSHOT, the Rytm's sample slot) and the filter's FRQ |

Synfact (`../external/synfact-dev`, GPL-2.0-or-later) gave the id space and the lock routines
(`elekloader/sdk/include/syntakt/pattern.h`, `docs/RANDOMIZE-PAGES.md`, `mods/lfo3-st/actions.c`); no code was
copied. Nothing from digikit was used.

## Decisions taken

- Left out, as on the Rytm: two-value switches (PNCH, FENR, AENR, ROUT), selectors (filter TYPE; LFO MULT, WAVE,
  DEST, MODE; amp MODE). Machine controls with a few steps (BD HARD's WAVE 0..2, CY RIDE's TYPE 0..3) are kept:
  they are sounds, not modes.
- The amp page's SUS and REL are left out: stock 1.42 does not show them (the amp envelope is AHD).
- CP CLASSIC (type 21) is in the firmware but in no machine menu: left out.
- The delay and reverb (owners 0x31, 0x32) are on no track's pages in 1.42 (the FX track's SYN page is FX Drive):
  left out.

## Open points

- **For the lead (a contract request):** `struct seed_param.id` is a `uint8_t` and `seed_caps.nparams` a `uint8_t`;
  the Syntakt's stock ids reach 504, and all machines' controls together are more than 255. st_params.h keeps
  stock ids in a `uint16_t` array beside each list and builds one list per track (SD4), so `lib/seed.h` is
  unchanged. If lib/ should carry stock ids, `seed_param.id` needs 16 bits.
- How a lock is stored (its row, its encoding) is S0.4's: this catalogue gives ids and ranges only.
- Lane values are whole units; TUNE's 40..88 (±24 semitones) and LFO SPD's fraction are stored in 8.8: the device
  layer converts (S2.1).
