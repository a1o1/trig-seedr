# trig-seedr: notes for agents

Version 1 is being built to a written design and plan. Before changing anything:

1. Read `docs/design-v1.md` (the specification) and `docs/plan-v1.md` (tasks, file owners, gates).
2. Work only on the task you were given, in its own worktree and branch, in the files that task owns.
3. Follow the hard rules in `docs/plan-v1.md` section 2. In short: never commit Elektron firmware, anything built from it, or Ableton-derived groove data; never write the owner's email address anywhere; Conventional Commits; nothing goes to `main` except through the lead.

Environment and test commands: `docs/plan-v1.md` section 3. What exists today (0.3): `README.md`, `docs/requirements.md`, `docs/firmware-notes-os174.md`, `tools/README.md`.
